# Day 01

## Topics Covered
- Variables (`let`, `const`)
- Data Types
- `typeof`
- `null`
- `undefined`
- Implicit Type Conversion
- Explicit Type Conversion

## Key Learnings
- `let` can be updated.
- `const` cannot be reassigned.
- `typeof` returns the type of a value.
- `null` is an intentional empty value.
- `undefined` means no value has been assigned.
- JavaScript automatically converts types in some operations.
- `Number()`, `String()`, and `Boolean()` perform explicit conversion.
